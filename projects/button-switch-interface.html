01 / What I built

From input to useful output

This prototype follows a simple embedded-systems pattern: read an input or state, apply program logic, and control an output. The goal is to make the behaviour visible and testable rather than keeping the logic theoretical.

InputDebounceState logicWokwi
02 / Practical direction

Why this matters

The same pattern can be extended into small automation products. Suggested directions include one-button toggle, irrigation override, RGB selector. These are application ideas, not claims that every extension has been fully implemented.
